# HIMIG Mobile & PWA Documentation



## Overview



HIMIG is a responsive web application designed to provide a mobile-app-like experience for worship teams.



The application is built as a Next.js web application with Progressive Web App (PWA) support.



The mobile experience focuses on:



- Fast access to the song library

- Responsive navigation

- Mobile-friendly song viewing

- Mobile-friendly setlists

- Worship Mode for live service use

- Touch-friendly controls

- PWA installation support

- Dedicated HIMIG application branding



The goal is to provide a practical worship-team experience on phones and desktop devices without maintaining separate native mobile applications.
